# weather

A simple weather application built using HTML, CSS, and JavaScript that fetches real-time weather data using an API.

# Features

1.Search for weather by city name
2.Displays temperature, humidity, and wind speed
3.Shows weather icons based on conditions
4.Responsive design for mobile and desktop

# Technologies Used

1.HTML – Structure of the app
2.CSS – Styling and layout
3.JavaScript – Fetching weather data and dynamic UI updates
4.OpenWeatherMap API – To get real-time weather data

#API Setup

1.Sign up on OpenWeatherMap
2.Get your API key
3.Replace "YOUR_API_KEY" in script.js with your actual key
